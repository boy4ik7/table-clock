# Table Clock
#### ESP32/ESP8266 Weather from <a href="https://open-meteo.com/"> Free Weather API</a>

Components:
- Sensor touch TTP223B;
- AHT10;
- LCD1602;
- Module esp32 or esp8266;
- Buzzer.
